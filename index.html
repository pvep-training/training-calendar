Nhập từ Excel

Tải file mẫu, kiểm tra dữ liệu và xem trước trước khi nhập vào hệ thống.

1. Tải file Excel mẫu

Sử dụng đúng cấu trúc mẫu để website nhận diện khóa đào tạo và danh sách học viên. Hai cột Tổng chi phí và Số hợp đồng chỉ Admin được nhập.
↓ Tải file Excel mẫu

2. Chọn file cần kiểm tra

File được đọc ngay trên trình duyệt. Ở bước này chưa có dữ liệu nào được ghi vào Supabase và chưa sinh mã khóa.
Chưa chọn file.

3. Kiểm tra và xem trước

Chọn một file Excel để bắt đầu kiểm tra.
